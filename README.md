# fibmixx.github.io

Personal portfolio of Marc — live at **https://fibmixx.github.io/**

Plain static site (HTML + CSS + vanilla JS), no build step. Red/black/paper look with slanted panels, ransom-note lettering and wipe transitions.

- `index.html` — content (edit projects, journey, etc. here)
- `style.css` — all styling
- `script.js` — ransom lettering, wipe transitions, keyboard menu, filters, language toggle, favorites shelf & dialog
- `i18n.js` — all texts in English, Español, Català and 한국어
- `favorites.js` — the Off Duty shelf (covers live in `img/fav/`)
- `logo.jpg` — favicon
